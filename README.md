# Design System Configurator

Built page of a step-by-step design token configurator. Brand examples are simulations with estimated colors and open stand-in fonts; they are not official palettes. Embedded fonts are under the SIL Open Font License. The preview bundles React, Base UI and their dependencies under the MIT license, plus icons from Lucide (ISC), Phosphor (MIT) and Tabler (MIT). All are in `licenses/`.
